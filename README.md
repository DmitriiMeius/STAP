# Text Analyzer

Text Analyzer - desktop-приложение для извлечения и анализа текста из документов.

Проект стартует на базе подхода FileMerger: программа умеет читать разные форматы документов, нормализовать текст и показывать результат в одном окне. В отличие от FileMerger, основной сценарий здесь - не объединение файлов, а анализ текста.

## Что умеет

- Открывает один или несколько файлов.
- Поддерживает форматы: `TXT`, `RTF`, `PDF`, `DOCX`, `XLS`, `XLSX`, `FB2`, `FB2.ZIP`, `EPUB`, `HTML`, `HTM`, `MD`, `CSV`.
- Считает символы, слова, уникальные слова, предложения и абзацы.
- Показывает топ частотных слов.
- Строит краткую сводку по каждому файлу и по всем выбранным файлам.
- Экспортирует отчет в `.txt`.

## Как запустить

```bat
pip install -r requirements.txt
python main.py
```

Или на Windows:

```bat
run.bat
```

## Структура

- `main.py` - графический интерфейс и сценарий анализа.
- `text_core.py` - извлечение текста и расчет метрик.
- `requirements.txt` - зависимости Python.
- `.gitignore` - исключения для локальных файлов, сборок и пользовательских данных.
